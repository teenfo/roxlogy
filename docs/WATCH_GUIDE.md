# Roxlogy 워치 앱 화면 가이드 (v0.5.0)

Wear OS 앱의 화면 구조·조작·데이터 흐름 정리. 에르그 단독 모드와 PM5 연결은 별도 절로 상세히 다룬다.

```
메뉴
├─ 레이스 시뮬   (두 링 서클 · 32구간 기록)
├─ 오늘의 WOD    (폰이 푸시한 워크아웃 플레이어)
├─ 에르그        (PM5 단독 기록) ◀ 상세는 3절
├─ 목표          (목표 스플릿 확인)
├─ 보관함        (최근 세션 · 재전송)
└─ 설정          (햅틱 · AOD · 짐 모드 · PM5 테스트)
```

---

## 1. 메뉴

앱 진입 첫 화면. 브랜드 워드마크(ROXLOGY) 아래 세로 칩 리스트.

- **이어서 기록** — 진행 중이던 시뮬 스냅샷이 있으면 맨 위에 노란 칩으로 표시. 크래시·이탈 후 복구 진입점.
- 레이스 시뮬 / 오늘의 WOD / 에르그 / 목표 / 보관함 / 설정.
- 베젤(용두) 회전으로 스크롤 가능(ScalingLazyColumn).

## 2. 레이스 시뮬

8×1km 런 + 8 스테이션 + 록스존 IN/OUT을 **32구간**으로 계측하는 메인 기능. 서클(두 링) 화면: 바깥 옐로 링 = 스테이션 8조각, 안쪽 블루 링 = 러닝 진행.

### 시작 전 (IDLE)
- "8×1km + 8 스테이션 · 32구간 기록" 안내 + **[PM5 미리 연결]** 칩.
  워밍업 때 PM5에서 Menu → Connect 를 열고 이 칩을 누르면, 시뮬 내내 연결이 유지되어 운동 중 모니터를 만질 일이 없다(3.2절 연결 정책 참조).
- [시작] / [메뉴].

### 기록 중 (RUNNING)
- **T자 3분할**: 타이머(상단 전폭 30sp) + 좌 칸 심박(존 컬러, 자리 고정) + 우 칸 상황별 지표
  - 런: 거리(트래커) 또는 "탭=랩"
  - 머신 스테이션(PM5 연결 시): 라이브 W / spm
  - 그 외: 목표 대비 누적 diff + 구간 목표
- 헤더: `RUN n`(블루) / `STATION n` + 종목명 / `록스존 · 이동`. 머신 스테이션(SkiErg·Rowing)에서는 **종목명 자체가 PM5 연결 버튼** — 탭=연결, 연결되면 `Rowing ✓`.
- 하단 주 액션은 항상 같은 위치: [1km 완료] / [스테이션 시작] / [완료] / [런 시작] / [피니시].
- **좌 스와이프** → 컨트롤 페이지: [일시정지/재개] [랩 되돌리기] [시뮬 종료].
- **상하 스와이프** → 뷰 전환: ①링+타이머 ②상세(심박 존·PM5 라이브·구간 목표·다음 종목) ③스플릿 리스트.
- **퀵버튼(상단 물리 버튼)** = 현재 구간 랩. 장갑·땀 손 대응.
- **뒤로가기** = 종료 확인 다이얼로그(기록은 스냅샷으로 보존 → 메뉴 "이어서 기록").
- 화면 꺼짐: 포그라운드 서비스로 세션 유지, 워치페이스 하단 아이콘 원탭 복귀. 설정의 AOD 두 모드(화면 항상 켜기 / 앰비언트 간소 화면) 적용.

### 완료 (DONE → SENT)
총시간 + 목표 diff + 런/스테이션/록스존 합계 + 평균·최대 심박 요약 → [전송] / [↩ 랩 취소]. 전송 후 [새 시뮬].

## 3. 에르그 단독 (상세)

PM5(SkiErg/RowErg)를 직접 연결해 워크아웃 raw 를 수집하고, 1개 스테이션 세션으로 서버에 올리는 모드. 진입: **메뉴 → 에르그**.

### 3.1 화면 흐름

```
기기 선택 ─→ 연결 ─→ 시작 ─→ 기록 중 ─→ 종료 ─→ 확인 ─→ 전송
 (idle)                        (running)          (done)   (sent)
```

| 단계 | 화면 | 조작 |
|---|---|---|
| 기기 선택 | [SkiErg] [RowErg] 칩 + "PM5에서 Menu → Connect 를 연 뒤 선택" | 종목 탭 = 즉시 스캔 시작 |
| 연결 | "연결 중…" → "SkiErg 연결됨 ✓" + **모니터 이름(시리얼)** | 실패 시 사유 표시(3.4절) + [다시 연결] / [기기 변경] |
| 시작 | 연결됨 + 라이브 W·spm 미리보기 | [시작] = 워밍업 샘플 리셋 후 기록 개시 |
| 기록 중 | 타이머(30sp) + T분할: 좌 W·spm / 우 거리·페이스(/500m) | [종료]. 연결 끊기면 "연결 끊김 — 재연결 대기"(자동 복구) |
| 확인 | 소요 시간 + 샘플 수 + 평균 W | [전송] / [버리기] |
| 전송됨 | "전송됨 ✓ 세션 목록에서 곡선·지표 확인" | [새 기록] |

### 3.2 PM5 연결 — 반드시 알아야 할 것

- **PM5는 화면만 깨워서는 검색되지 않는다.** 모니터에서 **Menu → Connect** 를 눌러야 블루투스 광고가 시작된다. 워치의 스캔 타임아웃은 30초 — 워치에서 먼저 탭하고 PM5 메뉴를 열어도 충분하다.
- **시스템 블루투스 페어링 불필요.** 워치 설정에서 페어링하지 말 것 — 앱이 GATT 직결로 연결·관리한다.
- **기기 기억**: 연결에 성공한 PM5는 머신 종류별(ski/row)로 기억된다. 다음부터 스캔에서 그 기기가 보이면 대기 없이 즉시 연결. 안 보이면(다른 머신 사용 등) 신호가 가장 강한 PM5로 자동 폴백 후 새로 기억. 초기화는 설정 → [기억한 PM5 지우기].
- **한 PM5에는 한 기기만 붙는다**(single central). 누가 이미 연결한 모니터는 검색에 잡히지 않으므로 가로채기·오연결이 원천적으로 안 된다. 여러 명이 동시에 써도 각자 자기 모니터에만 붙는다.
- **어느 모니터인지 확인**: 연결되면 화면에 PM5 이름(예: `PM5 430123456`)이 표시된다. 모니터 하단 시리얼과 대조.
- **자동 재연결**: 기록 중 끊기면 워치가 대기 모드로 물러나 있다가 PM5가 다시 광고하는 순간 자동으로 재연결한다(워치 조작 불필요).

### 3.3 수집 데이터

| 종류 | 주기 | 내용 |
|---|---|---|
| 샘플 | 1Hz | 경과, 누적 거리, 페이스(/500m), spm, 파워(W), 칼로리 |
| 스트로크 | 스트로크마다 | 드라이브 길이·시간, 리커버리 시간, 스트로크 거리, 최대·평균 드라이브 힘, 스트로크당 일(J), 파워 |
| 스플릿 | 인터벌마다 | 스플릿 시간·거리, spm, 평균 페이스, 파워, 칼로리, 드래그 팩터, 심박 |
| 힘 곡선 | 스트로크마다 | 드라이브 힘 프로파일(파운드 시퀀스) |

전송 경로: **워치 → 폰(Data Layer) → 서버**. 폰 앱이 로그인 상태여야 하며, 전송 시점에 폰이 없어도 로그인 시 자동 회수된다. 서버 도착 후 세션 목록에 **⚡ SkiErg/RowErg 배지**로 표시되고, 세션 상세의 파워·페이스 곡선·PR·AI 코칭에 반영된다(분석 1~2분).

### 3.4 실패 문구별 원인

| 화면 문구 | 의미 · 조치 |
|---|---|
| 블루투스가 꺼져 있습니다 | 워치 블루투스 켜기 |
| PM5를 찾지 못함 · 주변 BLE 0대 | 스캔 자체가 안 됨 — 블루투스/권한 확인 |
| PM5를 찾지 못함 · 주변 N대 검색됨 (…) | 스캔은 정상, PM5가 광고 안 함 — **PM5에서 Menu → Connect** |
| PM5 연결 실패 (status N) / 연결이 지연됩니다 | GATT 오류 — 1회 자동 재시도 후 실패. 다시 탭 |
| PM5 로잉 서비스/상태 특성을 찾지 못함 | 비표준 기기·펌웨어 — 개발자에게 문구 전달 |
| 연결됨 ✓ 데이터 대기 중 | 연결 정상, 노를 저으면 수치 표시 |

## 4. 오늘의 WOD

폰 앱이 오늘의 프로그램 워크아웃을 워치로 푸시(`폰 로그인 시 자동 + 워치 탭 수동`). 워치는 플레이어 — 항목 체크와 소요시간만 기록한다(무게·횟수는 폰/웹에서).

- 현재 항목 카드(이름·노트·타이머 22sp) + [완료] → 다음 항목. 전체 완료 시 요약.
- **에르그 항목**(SkiErg/RowErg)은 PM5 연결 칩이 나타난다. 연결 후 수행하면 [완료] 시 raw 가 **별도 세션으로 자동 전송**된다(3.3절과 동일 파이프라인).
- 완료는 웹 체크리스트에 ✓ + "⌚ m:ss"로 역동기화.

## 5. 목표

폰이 보낸 목표 스플릿(goal_plans) 확인: 총시간 / 1km 랩(런÷8) / 록스존 1회(÷16) / 스테이션별 목표. 시뮬 중 diff 계산의 기준이 된다.

## 6. 보관함

최근 20세션 · 72시간 보관. 항목 탭 = 재전송(멱등 업서트라 중복 안전). 전송 상태(전송됨/대기/재전송함 ✓) 표시. 폰 미연결 상태로 기록했을 때의 복구 수단.

## 7. 설정

| 항목 | 기본 | 설명 |
|---|---|---|
| 햅틱 피드백 | 켬 | 랩·완료 시 진동 |
| 화면 항상 켜기 | 끔 | 시뮬 중 화면 유지 (배터리↓) |
| 앰비언트 모드 | 켬 | 화면 꺼짐 시 저전력 간소 화면 |
| **짐 모드** | 끔 | 켜면 머신 스테이션 **종료 시 PM5 연결 해제** — 내가 런 도는 동안 공유 머신을 점유하지 않음. 홈트레이닝은 끔(연결 유지) 권장 |
| PM5 연결 테스트 | — | 연결·라이브 수치 확인 (기록 안 됨). 실패 시 사유 표시 |
| 기억한 PM5 지우기 | — | 머신별 저장 기기 초기화 |

### 연결 유지 vs 짐 모드 (시뮬 중 머신 스테이션)

| | 연결 유지 (기본) | 짐 모드 |
|---|---|---|
| 스테이션 종료 후 | 연결 유지 — 같은 머신 복귀 시 즉시 기록 | 즉시 해제 |
| 다른 머신(스키↔로잉) | 자동 재스캔 | 종목명 칩 탭으로 연결 |
| 적합 환경 | 홈트·전용 머신 | 공유 짐 |
