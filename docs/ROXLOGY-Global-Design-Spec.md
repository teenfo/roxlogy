# ROXLOGY 전체 화면 디자인 — 실제 앱 적용 기준

버전 2.0 · 2026-09-20 · 브랜치 `feat/design-gaps-preview-og-onetap`

기존 리뉴얼 시안의 밝은 작업 공간을 원본 Next.js 앱 전체에 적용한다. 이 문서는 실제 코드 기준이다. 이전 시안의 가짜 데이터·임시 로고·인증 대체 로직을 가져오지 않는다. 페이지별 서버 조회, RLS, 저장, 회계 계산, 실시간 계측을 유지한다.

## 브랜드 자산

| 요소 | 원본 / 적용 위치 | 규칙 |
| --- | --- | --- |
| 기본 마크 | `brand/roxlogy-mark.svg` → `web/public/roxlogy-mark.svg` | PFT 다크 보드, 인증 브랜드 영역, 다크 공유 카드 |
| 반전 마크 | `brand/roxlogy-mark-inverse.svg` → `web/public/roxlogy-mark-inverse.svg` | 밝은 앱 내비게이션, 로그인, 오류·404, 밝은 공유 카드 |
| 워드마크·브랜드 제목 | 브랜드 가이드의 Archivo Black | `web/public/fonts/ArchivoBlack-Regular.ttf`, 원본과 동일한 파일, 라이선스 동봉 |
| 앱 UI·숫자·본문 | 기존 자체 호스팅 Pretendard Variable | 폰트 서브셋 유지, 숫자에는 tabular-nums |
| Race Yellow | `#FFD500` | 기본 CTA, 선택 메뉴, 진행 표시. 위 글자는 `#141414` |
| Track Blue | `#2D7DFF` | 러닝·진행 정보. 작은 글자에는 대비를 확보한 `#2166D7` 사용 |

SVG 경로, 8개 외곽 세그먼트, 파란 내부 링, R 심볼은 다시 그리거나 변경하지 않는다. 타 브랜드 자산을 사용하지 않는다. 브랜드 카피는 기존 다국어 랜딩 사전을 재사용한다.

## 색상과 표면

구현: `web/app/globals.css`, `web/app/renewal.css`.

| 용도 | 값 |
| --- | --- |
| 작업 공간 | `#F5F6F8` |
| 카드·헤더·사이드바 | `#FFFFFF` |
| 기본 글자 / 보조 글자 | `#25282D` / `#626D7B` |
| 기본 구분선 | `#E2E5EB` |
| 강조 카드 | `#FFF9E5`, 선 `#E4CC70` |
| 밝은 바탕의 강조 글자 | `#796100` |
| 성공 | 글자 `#27724E`, 배경 `#E7F3ED` |
| 오류 | 글자 `#B44248`, 배경 `#FCEEF0` |
| 정보 | 글자 `#236B91`, 배경 `#EAF4FB` |
| 키보드 포커스 | `#2D7DFF`, 2px outline |

배경과 글자 의미를 분리한다. `text-on-accent`는 노란 채움 위의 검정 글자, `text-on-solid`는 진한 의미 색 위의 글자다. `accent-ink`와 `track-ink`는 작은 텍스트용이다. 차트 툴팁·격자도 같은 토큰을 쓴다.

`data-theme="dark"`는 PFT 라이브보드, 주요 레이스 결과, 랜딩 데모에만 적용한다. 페이지 `#12171C`, 패널 `#181F26`, 선 `#2C353F`, 글자 `#F3F5F7`, 보조 글자 `#A8B4C1`. 계정 전체의 테마 설정을 새로 만들지 않는다.

## 공통 구조

- 데스크톱 사이드바 248px. 훈련 / 레이스 / 커뮤니티 그룹, 하단 프로필·관리자 진입. 메뉴명은 기존 ko/en/es 사전 사용.
- 헤더 74px. 현재 영역, 검색, 언어, 알림, 프로필. 공개 방문자는 공개 메뉴와 로그인만 표시.
- 본문 패딩 32×36px, 큰 화면 최대 1600px. 1200px 이하에서는 28×24px, 모바일 24×16px.
- 페이지 제목 30px/1.4, 모바일 25px. 카드 제목 17–20px, 본문 16px, 메타 정보 12–13px.
- 패널 반경 14px, 선 1px, 패딩 24px·모바일 20px. 주요 그리드 간격 24px, 좁은 화면 18px.
- 표는 패널 내부에서 가로 스크롤한다. 검색·필터·행 액션은 기존 동작 유지. 모바일에서 정보를 임의로 삭제하지 않는다.

| 관리자 | 계정/콘텐츠/크루/신고/PFT 레이스/사용자 목록과 사용자 상세. 실제 관리 액션·권한 유지 |
| 랜딩 | 기존 히어로 카피·CTA, 다크 기록 데모, 기능 3개, 실제 공개 크루 티커, 언어 선택 |
| 로그인·가입 | 좌측 원본 브랜드·태그라인, 우측 폼, Google·이메일·비밀번호 표시·유지 선택·오류. 모바일 폼 우선 |
| 네이티브 인증 | 브랜드 마크·진행/실패 안내. 기존 hash 즉시 삭제, 세션 수립, 안전한 내부 이동 유지 |
| 404·에러 | 마크·메시지·다시 시도/홈. 전역 에러는 번역 Provider 실패 시에도 독립적으로 렌더 |
| 로딩 | 22개 형태를 실제 라우트 loading boundary에 연결. aria-busy, 현재 언어 안내, reduced-motion |
| 권한 차단 | 정지 계정, 크루 로그인, 모임 멤버 전용, 회계 정회원 전용, 프로필 필수 안내 및 기존 복귀 동선 |

프로그램 미리보기는 로그인한 비소유자 시점이다. 편집·삭제·캘린더 토큰 재발급은 숨기고 복제는 보여준다. 소유자의 ‘편집으로’만 별도로 남기며, 본인의 등록 일정은 유지한다.

## 모달·기록지·외부 공유

자체 `components/ui/dialog.tsx`를 계속 사용한다. 명시적인 닫기 버튼, focus trap·복귀, Escape, 배경 inert, 스크롤 잠금, 최대 85dvh와 내부 스크롤을 제공한다. 긴 폼은 모바일 하단 시트로 전환하고, 짧은 확인창은 중앙에 둔다.

기록지는 기존 브라우저 canvas 합성이다. 사진은 업로드하지 않는다. 1080×1920/1080×1080, 자르기·맞춤·확대·배치·투명/사진 배경·다크/라이트 글자 선택을 유지한다. 워드마크는 Archivo Black, 각 테마에 맞는 원본 마크를 사용한다.

OG는 브랜드 공통 정적 1장과 공개 크루·모임 동적 2종이다. 비공개 정보는 카드에 노출하지 않는다. 자세한 권한·캐시·폰트 정책은 `DESIGN_GAPS_IMPLEMENTATION.md` 참조.

Google One Tap/FedCM은 브라우저·Google 소유 UI다. 색상·크기·위치를 흉내 낸 프롬프트를 만들지 않는다. 기존 노출 위치·쿨다운과 일반 Google 로그인 대체 경로를 유지한다.
