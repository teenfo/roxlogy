# 구글 원탭 (One Tap) 설정

리디렉트 없이 브라우저가 띄우는 "○○(으)로 계속하기" 카드로 로그인하는 기능.
코드는 이미 들어가 있고, **환경변수가 없으면 아무것도 뜨지 않는다** — 아래 두
단계를 마치면 켜진다.

## 1. 구글 클라우드 콘솔

Supabase Auth 의 Google 프로바이더에 등록한 **그 웹 클라이언트**를 그대로 쓴다
(새로 만들지 말 것 — 클라이언트가 다르면 Supabase 가 ID 토큰을 거부한다).

1. https://console.cloud.google.com/apis/credentials
2. OAuth 2.0 클라이언트 ID → 해당 **웹 애플리케이션** 클라이언트 열기
3. **승인된 JavaScript 원본**에 추가:
   - `https://roxlogy.com`
   - (미리보기에서도 쓰려면 해당 Vercel 도메인)
4. 클라이언트 ID 복사 (`...apps.googleusercontent.com`)

> 리디렉트 URI 는 건드리지 않아도 된다. 원탭은 리디렉트를 쓰지 않고
> **JavaScript 원본**만 검사한다. 기존 로그인 버튼(리디렉트 방식)은 그대로다.

## 2. Vercel 환경변수

`NEXT_PUBLIC_GOOGLE_CLIENT_ID` = 위에서 복사한 클라이언트 ID

Production·Preview 모두에 넣고 재배포한다. `NEXT_PUBLIC_` 접두사가 붙은 값은
브라우저에 노출되는데, 클라이언트 ID 는 원래 공개 식별자라 문제 없다
(비밀은 클라이언트 **시크릿**이고 그건 Supabase 대시보드에만 있다).

## 동작 위치

- 로그인·가입 화면
- **공개 크루 페이지**(비로그인일 때만) — 공유 링크를 받고 들어온 사람이
  페이지를 떠나지 않고 바로 들어올 수 있다. 이게 원탭의 제일 큰 효과다.

로그인한 사용자에게는 띄우지 않는다.

## 알려진 한계

- **이미 브라우저에 구글 계정으로 로그인된 사람에게만** 뜬다. 아니면 아무것도
  보이지 않으므로 기존 구글 버튼을 그대로 둔다.
- 크롬·엣지는 FedCM 으로 잘 동작한다. **사파리·파이어폭스는 지원이 제한적**이라
  안 뜰 수 있다.
- 사용자가 여러 번 닫으면 구글이 쿨다운을 걸어 한동안 뜨지 않는다(정상 동작).
- GSI 스크립트가 로드되는 순간 구글이 그 방문을 인지한다. 그래서 로그인한
  사용자에게는 아예 로드하지 않는다.

## 구현 메모

`components/google-one-tap.tsx`

nonce 를 양쪽에 다르게 넘겨야 한다 — **구글에는 SHA-256 해시(base64url)**,
**Supabase 에는 원문**. 같은 값을 양쪽에 주면 `signInWithIdToken` 이 검증에
실패한다. 토큰을 받으면 `supabase.auth.signInWithIdToken({ provider: "google" })`
로 세션을 만들고 `router.refresh()` 로 서버 컴포넌트를 다시 그린다.
