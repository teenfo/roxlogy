## 서버 계약 및 전체 경로 대조

- main의 페이지·route 파일 경로가 renewal에서 빠진 경우는 보완 후 **0건**이다. UI 대체로 삭제한 옛 shell/crew/nav 컴포넌트는 새 Rox 컴포넌트와 역할을 대조했으며 복구하지 않았다. 모바일 하단 탭 제거 결정도 유지한다.
- `web/app/api/` 8파일, Supabase Edge Functions 5파일, Android 120파일, Garmin 20파일은 main과 Git blob이 같다.
- main의 `supabase/migrations/` 184파일은 보완 후 모두 동일한 Git blob이다. 기존 182파일은 이미 같았고 113·114만 가져왔다. **DB에 SQL을 실행하지 않았다.**
- 113의 로그인·크루 접근 조건, 운영진 이메일 게이트, 114의 사용자 소유 세션 생성, 완주 취소/제거의 soft delete, 내부 SECURITY DEFINER helper의 권한 회수와 RPC grant를 원본 그대로 유지한다.
- PFT는 기존 6구간과 기본값 없는 구 응답의 fallback을 유지한다. 시뮬은 16/24/32구간 및 30분 이상 완주 세션 저장 계약을 사용한다. 서버에서 반환된 `session_id`가 있어야 “세션 보기”를 표시한다.
- 내 레이스 목록의 `user_id`/`created_by` 필터, `getCachedUser`·프로필·관리 권한 확인, RPC 실패 안내, Realtime·폴링·서버 오프셋·localStorage 큐를 유지했다.
- main의 알림 조회는 삭제된 것이 아니라 `lib/shell.ts → getShellData`로 이동했고, 사용자 필터와 unread count가 유지된다. 대시보드와 대회 상세의 select 차이는 추가 컬럼이다.
- ko/en/es에서 main의 번역 키 누락 **0건**, 중복 키 **0건**이다. 최근 기능용 누락 키 40개씩을 추가했다.
