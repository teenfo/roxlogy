대상은 `claude/design-renewal`의 `908b4b7`이다. `CLAUDE.md`, 브랜드 가이드 v4,
디자인 스펙 1.3·게시 v5, 모바일 가이드와 기존 이식 보고를 기준으로 점검했다.

## 공유 자산 출처

`feat/design-gaps-preview-og-onetap`의 `656cd2d`에서 OG 코드·정적 카드·폰트·라이선스를
선별 재사용한다. 브랜치 전체를 병합하지 않는다. 마크 SVG와 브랜드 색은 수정하지 않았다.
동적 OG의 한글은 브랜드 v4가 지정한 IBM Plex Sans KR Bold TTF(기존 Wear OS 자산),
워드마크는 Archivo Black이다. 이는 디자인 문서의 OG Pretendard TTF 계획과 다른 선택이며,
브랜드 자료의 기존 자산 우선 원칙에 따른다. 웹 UI 본문은 Pretendard를 유지한다.

OG 조회는 쿠키·service role을 사용하지 않는다. 공개·active 크루와 공개 모임만 허용하며,
다른 크루의 URL에 붙인 모임 UUID도 거부한다. 참가자는 수만 표시하고 이름·댓글·계좌는
공유 카드로 전달하지 않는다. 개인정보 회귀 테스트는 이 경계를 검증한다.

## 검증 및 남은 범위

- `git diff --check`, JavaScript 구문 검사, TS/TSX 구문 파싱을 로컬에서 실시한다.
- 실제 TypeScript·ESLint·운영 빌드는 기존 `web-ci`에서 실행한다.
- 신규 `design-audit`는 개인정보·실제 PNG 생성 회귀 테스트와 픽스처 빌드 후 12개 화면을
  320/360/375/390/430/600/767/768/1200px에서 검사한다. 모바일 드로어, 표 키보드 스크롤,
  모임 다이얼로그 닫기·포커스 복귀, 미리보기 소유자 액션 숨김, 폰트 로드와 입력 치수도 검사한다.
  언어 쿠키를 명시해 한국어로 검사하며 랜딩은 영어·스페인어도 같은 9개 폭으로 검사한다(총 126건).
  결과 JSON과 390/1200px 화면은 Actions 아티팩트에 남긴다. 실행 전에는 통과로 간주하지 않는다.
- 대비 스크립트는 텍스트 미달 10건을 보완한 뒤에도 지정 차트 1·2의 비텍스트 대비
  2건 때문에 exit 1이다(`2.01:1`, `2.89:1`). 범례와 수치를 함께 쓰는 지정 팔레트이며,
  전체 접근성 통과로 보고하지 않는다.
- 기존 Tailwind 도메인 컴포넌트 전체를 시안 마크업으로 다시 그리는 작업은 완료하지 않았다.
  이번 변경은 확인된 토큰 오류를 복구한다.
- 원본 시안의 육안 비교, 실기기 키보드·safe-area·회전·확대, 스크린 리더,
  운영 데이터 길이와 실제 계정별 권한, Google One Tap 브라우저 UI는 아직 미검증이다.
