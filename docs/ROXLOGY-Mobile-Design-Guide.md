# ROXLOGY 모바일 디자인 가이드 — 실제 앱 적용 기준

버전 2.0 · 2026-09-20

## 화면과 내비게이션

768px 미만에서 사이드바를 숨기고 60px 상단 바와 하단 탭바를 쓴다. 햄버거는 288px 메뉴 서랍을 연다. 서랍은 전체 높이이며 자체 스크롤과 닫기·포커스 복귀를 제공한다.

웹 하단 탭은 세션·훈련·레이스·크루·피드 5개다. 훈련과 레이스는 하위 메뉴 시트를 연다. 네이티브 WebView가 실제 `openWatch` 브리지를 제공하는 경우에만 Watch 탭을 추가한다. 일반 브라우저에서 흉내 낸 Watch 화면을 만들지 않는다.

탭바의 safe area를 포함해 본문 하단 여백을 둔다. 프로그램 편집 툴바와 세션 저장 바는 탭바 위에 위치한다. 키보드가 열린 경우 긴 폼·시트 내부를 스크롤해 입력·저장에 접근할 수 있게 최대 높이를 dvh로 제한한다.

## 크기와 터치

| 요소 | 기준 |
| --- | --- |
| 페이지 좌우 여백 | 16px |
| 페이지 제목 | 25px / 1.4 |
| 폼 글자 | 16px, iOS 자동 확대 방지 |
| 입력 높이 | 48px |
| 주요 액션·탭 터치 | 44px 이상, 주 저장 버튼 48px |
| 패널 패딩 | 20px |
| 패널 간격 | 18–24px |
| KPI | 2열, 간격 12px |
| 모달·시트 최대 높이 | 85dvh, 내부 스크롤 |
| 하단 safe area | `env(safe-area-inset-bottom)` |

상태는 색상만으로 설명하지 않고 기존 텍스트·배지를 함께 유지한다. 중요한 작은 글자는 최소 12px. 포커스 링은 파랑 2px. 애니메이션·깜빡임·부드러운 스크롤은 reduced-motion 설정에서 제거한다.

## 화면별 전환

- 대시보드: KPI 2열 → 최신 레이스 → 오늘 일정 → 기록 → 분석. 각 카드가 컨테이너 폭을 따른다.
- 회계: 1100px 이하에서 본문 다음 보조 영역. 중간 폭에는 보조 카드 2열, 입력 카드는 전체 폭. 600px 이하에서는 전부 1열이다.
- 러닝: 입력 다음 실시간 페이스 요약·저장. PFT 입력은 기존 결과 미리보기·입력 순서를 유지한다.
- PFT 스태프: 상단 2개 패널을 1열로, 선수 카드를 2→1열로 전환한다. 기존 웨이브 선택·시작·구간 완료 액션을 유지한다.
- 라이브보드: 1200px 미만 1열, 스테이션 2→3→6열. 진행·완주 상태를 삭제하지 않는다.
- 크루: 길어진 탭은 줄바꿈 대신 탭 내부 가로 스크롤. 모임 상세와 내 레이스 계획의 날짜·제목·버튼은 모바일에서 재배치한다.
- 설정: 본문 카드가 1열, MCP 엔드포인트·토큰 행은 세로로 쌓인다. 토큰은 기본 마스킹이고 기존 표시·복사 동작을 유지한다.
- 인증: 폼 먼저, 브랜드 영역은 아래. 언어 선택은 폼 위. Google 버튼·유지 선택·입력 오류를 유지한다.
- 목록/표: 필터 칩·표만 내부에서 가로 스크롤. 이름·제목은 말줄임 또는 줄바꿈으로 처리하며 페이지 전체 가로 스크롤에 의존하지 않는다.

## 시트와 대화상자

기존 자체 Dialog를 사용한다. `scroll` 긴 폼과 `sheet` 메뉴는 모바일에서 화면 아래에 붙으며 모서리 20px이다. `center` 확인창은 중앙에 남긴다. 명시적 닫기, Escape, 백드롭 닫기, Tab/Shift+Tab 순환, 배경 inert, body 스크롤 잠금, 원래 포커스로 복귀를 유지한다.

Google One Tap은 커스텀 시트로 대치하지 않는다. FedCM의 브라우저 UI와 비지원 브라우저의 Google SDK UI를 그대로 사용한다.

## 검증 범위

320·390·768·1440px에서 확인할 항목: 문서 가로 넘침, safe area, 입력 폰트, 키보드 뒤 저장 접근, 시트 포커스, 긴 스페인어 메뉴, 실제 네이티브 Watch 브리지, PFT 진행 중 화면.

이번 환경의 원격 브라우저는 로컬 서버 접속을 `ERR_BLOCKED_BY_CLIENT`로 차단했다. 따라서 위 뷰포트의 실제 브라우저 캡처·터치·키보드 상호작용 검증은 완료했다고 표기하지 않는다. 대신 타입·빌드, 모든 페이지의 로컬 서버 렌더와 권한 상태를 검증한다. 운영 Google/FedCM·네이티브·푸시는 해당 실제 환경에서 추가 확인해야 한다.
